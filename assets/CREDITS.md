# RoverWatch — credits and provenance

## Curiosity 3D model

Official model: NASA/JPL-Caltech, “Curiosity Rover 3D Model.”
https://science.nasa.gov/resource/curiosity-rover-3d-model/

Original file retained: `curiosity.glb` (11,860,016 bytes).
Source: https://assets.science.nasa.gov/content/dam/science/psd/mars/resources/gltf_files/24584_Curiosity_static.glb

Resources and usage guidelines:
https://science.nasa.gov/3d-resources/
https://www.nasa.gov/nasa-brand-center/images-and-media/

The asset is a textured static mesh. Camera movement and turntable rotation do not simulate mechanical articulation. Landmarks are educational and are not connected to anonymized telemetry channels. This project is not affiliated with or endorsed by NASA, JPL, or Caltech.

## Data and research

Current study: Curiosity REMS MODRDR, MSL-M-REMS-5-MODRDR-V1.0, sols 100–109.
Instrument team: Centro de Astrobiología / J. Gómez-Elvira and collaborators. Archive: NASA Planetary Data System.
https://pds.nasa.gov/ds-view/pds/viewProfile.jsp?dsid=MSL-M-REMS-5-MODRDR-V1.0
https://atmos.nmsu.edu/PDS/data/mslrem_1001/

PDS data usage: https://pds-geosciences.wustl.edu/faq.html
Derived data retain source links and SHA-256 checksums in data/rems-manifest.json.
Quality flags and missing values follow MODRDR6.FMT and ERRATA.TXT; study-specific aggregation and exclusions are documented in Methods.

## Design and development

Project direction: Mehdi, with AI assistance. Composition inspired by the visual reference supplied by Mehdi. The vector logo and interface were created for this project. NASA Open MCT (Apache 2.0) provided conceptual inspiration without copied code: https://github.com/nasa/openmct

This version requires no assets generated by a paid service. Libraries, data, and the model are served locally. External documentation links open only when selected.
