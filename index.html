Units and meaning

Air temperatures are local measurements at each boom; they may include rover effects. Ground temperature is a radiometric brightness temperature, not a universal surface temperature. Celsius = Kelvin − 273.15. Pressure is in pascals. A sol is a Martian day; LMST is local mean solar time. Unknown and −999 values become missing, never zero.

THE RESEARCH PROCESS

From a question
to a clearer picture.

Six steps. One traceable path from original Mars measurements to findings you can inspect.

  1. 01
    Scope: sols 100–109

    Start with a question

    What changes in Curiosity’s environment, and which observations deserve a closer look?

    ResultA ten-sol exploratory study, with no forecasting or fault-diagnosis claim.

    How it was done

    This study uses four named REMS measurements: local air temperature at two booms, atmospheric pressure, and ground brightness temperature. The interval is deliberately bounded; it cannot establish mission-wide or seasonal behavior.

    Meet the data ↗
  2. 02
    NASA PDS · REMS MODRDR

    Go to the source

    Retrieve the original measurements from NASA’s Planetary Data System.

    Result306,257 original records, with source links and checksums.

    How it was done

    Download ten original tables and their detached labels. Parse fixed-width columns using MODRDR6.FMT, validate file sizes and row counts, and retain SHA-256 provenance. Check duplicate sol/timestamp pairs; do not silently delete them.

    Inspect the sources ↗
  3. 03
    Missing values · Quality flags

    Check before analyzing

    Separate unavailable values and quality exclusions from usable observations.

    ResultAn explicit audit for each measurement.

    How it was done

    Convert the −999 sentinel to missing. Air: reliability bit 7 must be 1. Pressure: no-shadow bit 1 must be 1; bit 0 identifies the oscillator, not a quality failure. Ground: power, recalibration, stationary rover, and no-shadow bits 0–3 must all be 1. These choices do not guarantee that every retained value is perfect.

    Read notebook 01 ↗
  4. 04
    Individual observations · 10-minute and hourly views

    Reveal the daily rhythm

    Compare like with like, at the same local time of day.

    ResultIndividual measurements, interval medians, and a daily reference profile.

    How it was done

    Aggregate accepted observations into ten-minute or hourly local mean solar time (LMST) bins. Require at least ten accepted observations per measurement and bin. The individual view shows each quality-accepted, NASA-processed measurement, one sol at a time. The standard chart connects across gaps as a visual guide; no missing measurements are created. The optional LOWESS trend uses local weighted linear regression with a 2-hour radius and up to two robust reweightings. It splits at gaps longer than 2 hours and needs at least two nearby points. In the individual view it uses five-minute medians; fitted values are estimates, not measurements. Build the reference profile from the median across available sols at each local time, weighting each contributing sol equally.

    Explore the daily cycle ↗
  5. 05
    Median / MAD · Review threshold 3.0 by default

    Look beyond the expected

    Review departures from the daily rhythm, instead of treating every extreme as a fault.

    ResultCandidate observations, with sensitivity to the chosen threshold.

    How it was done

    Subtract the same-local-time median, requiring at least five contributing sols. For residual r, calculate s = |r − median(r)| / (1.4826 × MAD(r)). Review s > 3.0 by default and compare cutoffs 3.5 and 4.5. Individual observations use the hourly same-time profile and the hourly residual median and MAD from the ten-sol study; nearby flagged samples may belong to the same episode, not separate failures. The 1.4826 scale factor does not set a 99% threshold. Zero-scale scores are unavailable. This descriptive baseline uses the same dataset; it imposes no anomaly percentage and establishes no detection accuracy.

    Read notebook 02 ↗
  6. 06
    Standardized PCA · Evidence with limits

    Connect the patterns

    Compare relationships, then summarize the measurements together.

    ResultCorrelation matrices and a PCA built from 579 complete 10-minute bins.

    How it was done

    Compare raw correlations with daily-profile-adjusted correlations, noting their different eligible samples. Standardize the four variables using sample standard deviations and compute PCA by SVD. The correlation circle shows variable–component correlations, not physical sensor positions. Publish the findings alongside three executed notebooks; association is not causation and review candidates are not confirmed failures.

Limits that matter

Ten sols cannot establish seasonal patterns. Sampling is uneven; quality filtering changes coverage. Temporal dependence makes adjacent bins non-independent. Shared daily cycles are not evidence of causation. The same-data daily profile may mask persistent departures. Flagged bins have no ground-truth failure labels and are never described as confirmed faults. The 3D rover illustrates hardware; it does not reconstruct a drive or sensor position from the data.

What happened to Isolation Forest?

The earlier anonymized-telemetry benchmark is preserved in version history. This study answers a different question using named physical measurements and descriptive statistics. Machine learning is not required for this question.
